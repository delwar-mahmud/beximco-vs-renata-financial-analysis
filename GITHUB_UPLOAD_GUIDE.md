# Put this project on GitHub

## Suggested repository details

Name: `beximco-renata-financial-analysis`

Description: `Excel-based financial and business performance analysis of Beximco Pharma versus Renata, 2019–2021, using ratio analysis, PESTLE and SWOT.`

Suggested topics: `financial-analysis`, `excel`, `equity-research`, `pharmaceuticals`, `business-analysis`, `bangladesh`, `research-portfolio`.

## Upload through GitHub

1. Extract the downloaded ZIP file on your computer.
2. Sign in to GitHub and create a repository using the suggested name and description. Choose Public if you want it visible as a portfolio.
3. Upload the contents inside the extracted project folder, including its subfolders. Place `README.md` at the repository root rather than inside an extra project folder.
4. Commit the uploaded files with a message such as `Add pharmaceutical financial research portfolio`.
5. Open the repository and check that the README chart displays and the workbook and presentation download links work.
6. Add the suggested description and topics to the repository's About section. Pin the repository on your profile if you want visitors to see it prominently.

## Optional command-line route

Run these commands from inside the extracted project folder. Replace YOUR_USERNAME with your GitHub username and create an empty remote repository first.

```bash
git init
git add .
git commit -m "Add pharmaceutical financial research portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/beximco-renata-financial-analysis.git
git push -u origin main
```

No GitHub account changes or uploads have been made by preparing this package.
